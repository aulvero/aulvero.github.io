Aulvero is a GitHub organization. Our ambition is simple: **build the most capable language models we can, with fewer parameters and a lower memory footprint.**

We want useful intelligence to fit into more places. That means treating model quality and the resources needed to run it as parts of the same problem.

## Small is a design constraint

A smaller model is only useful if it can do useful work. Our focus is general-purpose language modeling: improving capability while paying close attention to the memory required to deliver it.

We are interested in how architecture, training data, and training choices work together. The objective is to get more from the resources a model uses.

## Where we are today

We have no models to announce yet. There are no released weights or benchmark results on this website.

The [documentation](/docs/) covers the current training code and example configurations. Those examples are not model announcements.

## What comes next

We will use this space for project updates, research notes, and model announcements when they are ready. Model cards will appear on the [Models](/models/) page, alongside the information needed to understand what each model can do and what it takes to run it.
